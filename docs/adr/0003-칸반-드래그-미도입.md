# ADR 0003. 칸반 드래그 이동 미도입

- 상태: 확정
- 일자: 2026-09-22

## 맥락

대시보드에 태스크 칸반이 있다. 칸반 UI를 보면 드래그로 카드를 옮기는 기능을 기대하게 되고, 데모에서도 보기 좋다는 의견이 나올 수 있다.

## 결정

**드래그 이동을 넣지 않는다. 드래그 라이브러리도 추가하지 않는다.**

`TaskState` 9종의 전이는 서버 상태 기계가 결정한다. 에이전트 작업 결과, 검증 통과 여부, 사람의 승인이 전이 조건이며 사람이 카드를 끌어다 놓는 행위는 그중 어디에도 해당하지 않는다.

드래그를 허용하면 두 가지가 깨진다.

1. 사용자가 상태를 직접 바꿀 수 있다는 잘못된 모델을 학습시킨다
2. 서버가 거부할 전이를 화면이 먼저 보여주게 되고, 되돌리는 애니메이션은 버그처럼 보인다

## 결과

- 칸반은 읽기 전용 보드다
- 태스크에 대한 사람의 개입은 **승인 카드와 질의 카드를 통해서만** 이뤄진다
- `dnd-kit` 등 드래그 라이브러리를 의존성에 추가하지 않는다

## 재검토 조건

명세에 "사람이 태스크 상태를 직접 전이시킨다"는 요구가 추가되면 다시 논의한다. 그 경우에도 드래그는 서버에 전이 요청을 보내는 수단일 뿐이며, 낙관적 업데이트는 하지 않는다.
