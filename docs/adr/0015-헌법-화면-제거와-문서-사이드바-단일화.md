# ADR 0015. 헌법 화면을 없애고 문서 화면은 앱 사이드바만 쓴다

- 상태: **확정**
- 일자: 2026-10-28

## 맥락

10.28 FE 피드백(노션 "피드백"). 헌법은 서버 API가 없어 목업 문서만 보여 주고 있었고, 실제 프로젝트에서는 "API 연결 전" 빈 상태였다. 문서 화면은 앱 사이드바의 "문서 (MCP)" 목록과 같은 목록을 화면 안 왼쪽에 한 번 더 그렸다(MCP 도구 안내 포함).

기능명세서는 MCP 문서 페이지에 헌법을 둔다(§245, §591). 이 결정은 명세와 다르며, 대표(사용자)의 요청에 따른 것이다.

## 결정

- 사이드바·대시보드·문서 화면에서 헌법을 뺀다. `/docs/constitution` 같은 모르는 주소는 명세로 보인다.
- 문서 화면 안의 왼쪽 목록과 MCP 도구 안내를 지운다. 문서 이동은 앱 사이드바로 한다.
- 헌법만 쓰던 목업 화면(`MockDoc`)을 지운다. `DocType`의 `CONSTITUTION`과 목업 스토어 데이터는 `lib/store` 해체 때 함께 정리한다.

## 재검토 조건

- BE에 헌법 API가 생기면 명세처럼 문서 목록에 다시 넣는다.
