# ADR 0012. 1회용 연결 명령 · 취소 상태 위치 · 평가 화면은 별도 라우트

- 상태: **확정** (BE 10.23)
- 일자: 2026-10-24

## 맥락

BE 10.23에서 세 가지가 바뀌었다.

- 노트북에 예전 계정 자격 증명이 남아 있으면 새 계정으로 가입해도 예전 계정으로 연결됐다. 그래서 서버가 `POST /me/agent-connect-codes`로 계정 전용 1회용 명령(10분)을 준다.
- 태스크 상태에 `CANCELLED`가 생겼다. 명세는 칸반에서 "완료와 같은 줄에 두거나 숨김 필터"를 두라고 했다.
- 발표 평가용 라우팅 보고서(`GET /projects/{id}/routing-report`)가 생겼다. 대표 전용이다.

## 결정

- 온보딩 3단계의 고정 명령 `connect`(브라우저 승인, adr/0008)를 **서버가 준 `command`**로 바꾼다. 화면에 들어오면 바로 발급하고, 만료 시각과 "새 명령 받기"를 함께 보여준다. 브라우저 승인 화면(`/connect/device`)과 연결 키 방식은 남겨 둔다.
- `CANCELLED`는 칸반 **완료 열에 회색(neutral) "취소됨"**으로 둔다. 숨김 필터는 만들지 않는다.
- 라우팅 보고서는 **별도 라우트 `/p/[projectId]/eval`**에 둔다. 사이드바에는 넣지 않고 URL로만 들어간다. 정답 담당자(gold)는 답이 끝난 질문 카드의 접힌 "평가" 영역에서 붙인다.

## 결과

- 명령이 계정마다 달라서, 랜딩처럼 로그인 전 화면에서는 이 명령을 보여줄 수 없다. 랜딩 안내는 그대로 둔다.
- 대시보드의 완료 개수는 DONE만 센다. 취소된 태스크는 완료 열에 보이지만 진척률에는 들어가지 않는다.
- 평가 화면은 발표가 끝나면 지워도 서비스에 영향이 없다.

## 재검토 조건

- 취소된 태스크가 많아져 완료 열이 지저분해질 때: 숨김 토글을 둔다.
- 평가 지표를 상시 운영 지표로 쓰게 될 때: 사이드바나 설정에 노출한다.
