## 규칙

- **명세와 코드가 다르면 명세가 맞다.** 코드를 고칠 것
- 명세에 없는 결정을 만나면 지어내지 말고 질문할 것
- 결정을 새로 내렸으면 `adr/`에 한 장 남길 것
- `.docx` 파일은 제출용 원본이며 참조 대상이 아니다. 내용이 필요하면 위 md를 볼 것
